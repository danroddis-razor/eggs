# Tokens

Put these on `:root` in `styles.css` and use them everywhere. Use the dark values under `@media (prefers-color-scheme: dark)`.

| Token | Light | Dark | Use |
|---|---|---|---|
| `--bg` | `#fbf8f3` | `#1d1b18` | Page background |
| `--surface` | `#ffffff` | `#28251f` | Cards, tables, inputs |
| `--text` | `#2b2620` | `#f2ede4` | Body text |
| `--muted` | `#6f675c` | `#b5ac9e` | Secondary text |
| `--accent` | `#e0a526` | `#f0b93a` | The one primary action, a running timer |
| `--line` | `#e7e0d5` | `#3a352d` | Borders and rules |
| `--space` | `8px` | `8px` | The unit: use 1×, 2×, 3× or 4× |
| `--radius` | `10px` | `10px` | Cards and inputs |
| `--font` | `system-ui, sans-serif` | same | All text |

One filled button per region. Others are outlined or plain.
